# 3D Interactive Portfolio — Apple-Inspired Design System & Data in Motion

A high-performance, responsive single-page portfolio skeleton for a **Data Science graduate focusing on Manufacturing Analytics, Machine Learning, and Industrial AI**.

Built with **React 19, Vite, TypeScript, Tailwind CSS, Three.js, React Three Fiber, Drei, and Motion for React (Framer Motion)**.

---

## 🎨 Hero Concept: DATA IN MOTION

The Hero Section recreates the creative composition of an intelligent manufacturing analytics architecture:

1. **Raw Data Cubes (Left / Lower Mid-ground)**:
   - A cluster of floating geometric cubes in slate blue, pale cyan, and lavender, with highlighted pastel pink anomaly cubes resting on and hovering just above the reflective dark floor plane.
2. **Luminescent Fiber Streamlines**:
   - Dense bundled splines surging upward from the cube field, curving rightward through transformation filters in a vibrant electric-cyan and lavender glow.
3. **Translucent Glass Monoliths (Center)**:
   - Three upright frosted glass slabs with glowing cyan beveled edges representing the analytical transformation / model inference pipeline.
4. **Structured Network Lattice (Right)**:
   - As the data stream passes through the glass monoliths, it expands into an organized 3D neural/graph constellation of spherical nodes, featuring pulsating magenta/pink anomaly detection nodes.
5. **Dark Reflective Ground**:
   - Glossy, dark floor plane capturing subtle specular reflections from the streamlines and data cubes.

## 📖 About Section: BEHIND THE NUMBERS

Refined in place into a two-part Apple-inspired interactive narrative:

1. **Part 1 — Sticky 3-Stage Storytelling**:
   - Desktop sticky viewport with narrative text on the left and a 3D morphing data transformation on the right:
     - **01 — CURIOSITY**: *"Every dataset starts with a question."* (Particles dispersed in raw, curious 3D cloud).
     - **02 — EXPLORATION**: *"Patterns turn complexity into clarity."* (Particles align into harmonic, flowing streamlines).

2. **Part 2 — Final Reveal: Personal Introduction**:
   - Heading: `"Hi, I'm Chakrapong."`
   - Preserved editable biography blocks, philosophical footnotes, and seamless progression into Experience.

##  Apple-Inspired Design System

- **Editorial Typography**: Apple-style system font stack (`-apple-system, BlinkMacSystemFont, "Helvetica Neue", Helvetica, Arial, sans-serif`) with fluid `clamp()` sizing, negative letter-spacing, and crisp hierarchy.
- **Hero Composition**:
  - Left-aligned headline: `Data. Insight.\nImpact.`
  - Subtitle: `Transforming complex data into meaningful decisions through data science, machine learning, and manufacturing analytics.`
  - White pill CTA: `Explore projects →`
  - Underlined link: `Download resume`
  - Center bottom: Mouse scroll indicator with animated dot + `SCROLL TO EXPLORE`.
- **Navigation Bar**: Clean top header with `CP.` monogram and centered links (`Home`, `About`, `Experience`, `Projects`, `Skills`, `Contact`) with active underline indicators.
