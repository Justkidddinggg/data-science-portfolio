# Editing the Projects carousel

- `src/components/Projects.tsx`: Featured BELTON card, project carousel, arrows, and SECOM expandable case study.
- `src/components/ProjectsEditorial.css`: All Projects styling. The new carousel styles are at the end.
- `public/images/secom-roc-curve.png`: SECOM ROC plot. Replace this image to update the preview.
- `src/data/portfolio.ts`: Original portfolio project data and technology tags.

The SECOM result shown is **out-of-fold ROC-AUC 0.760** (not Kaggle test AUC).
The BELTON dashboard uses synthetic demonstration data. Its GitHub link is labeled forecasting-only.

Run: `npm install` then `npm run dev`.
